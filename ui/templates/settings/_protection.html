{# ---- 4. Advanced: how strict -------------------------------------------- #}
How strict to be

Every catch is graded by its worst finding: programs and scripts are critical, archives and a main file that is too small are high, suspicious file names are medium. These two settings decide what each grade leads to.

{% set grades = [('LOW', 'Anything suspicious'), ('MEDIUM', 'Medium and worse'), ('HIGH', 'High and worse'), ('CRITICAL', 'Only critical')] %}
Anything milder is recorded but left alone.
Anything acted on but milder than this is held for review instead.

To grade a particular file type differently (for example treat .rar as low), add it under remediation.severity_overrides in the config file.

{# ---- 5. Advanced: when the arr is down --------------------------------- #}
If Sonarr, Radarr or Lidarr can't be reached
Removing it anyway stops the download, but Sonarr won't know to block that release or look for another. "Try again later" uses the retry settings on the Scanning tab; with retries off it just leaves it.
